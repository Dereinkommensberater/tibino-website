Nursery rhymes, kids songs & fun farm rescue stories for toddlers, babies and preschoolers.

## Tech

Static HTML/CSS, optimized for performance & SEO:

- Semantic HTML5 with ARIA landmarks
- Schema.org structured data (WebSite, Organization, VideoObject)
- Open Graph + Twitter Card meta tags
- WebP images, lazy loading, preloaded fonts
- Mobile-first responsive design
- robots.txt + sitemap.xml
